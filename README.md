# DeckCast — плагин Decky Loader (второй экран на телефоне)

Запускает «второй экран» прямо из боковой панели Steam в игровом режиме:
видео уходит на телефон по Wi-Fi, а **звук играет в наушниках Steam Deck**.

## Что нужно один раз сделать перед установкой

1. **Decky Loader** должен быть установлен на Деке (https://decky.xyz).
2. **Компоненты ставятся сами.** При первом открытии плагина нажми
   **«⬇ Установить компоненты»** — плагин сам скачает `ffmpeg` и `yt-dlp`
   в свою папку `bin/` (нужен интернет на Деке, ~1–2 минуты, разово).
3. Фильмы клади в `/home/deck/Videos` (папка создаётся автоматически).

> Ручная установка не нужна. Если интернета на Деке нет — можно положить
> бинарники `ffmpeg` и `yt-dlp` в `bin/` руками, плагин их подхватит.

## Два способа смотреть

- **Ссылка (YouTube и т.п.)** — на странице телефона вставь ссылку в поле и нажми «Играть».
- **Файл** — выбери видео из списка папки `~/Videos`.

В обоих случаях картинка на телефоне, звук — в наушниках Деки.

## Установка плагина

**Вариант А — через zip:**
1. Скопируй `DeckCast.zip` на Дек.
2. В Decky (значок штекера в Quick Access) → шестерёнка → *Developer Mode* → *Install Plugin from ZIP*.

**Вариант Б — вручную:**
Распакуй папку плагина в `~/homebrew/plugins/DeckCast/` и перезапусти Decky
(или `sudo systemctl restart plugin_loader`).

## Как пользоваться

1. В игровом режиме открой Quick Access (кнопка «…») → значок Decky → **DeckCast**.
2. Нажми **▶ Запустить стрим** — появится адрес вида `http://192.168.x.x:8777`.
3. Открой адрес в браузере телефона (Chrome). Телефон и Дек — в одной Wi-Fi.
4. Выбери видео. Картинка — на телефоне, звук — в наушниках Деки.
   Ползунком на странице подгони синхрон звука и картинки.

## Структура

```
DeckCast/
├── plugin.json        # манифест плагина
├── main.py            # бэкенд: старт/стоп стрима, маршрут звука в сессию deck
├── dist/index.js      # собранный фронтенд (кнопка в панели)
├── bin/
│   ├── server.py      # HTTP-сервер + ffmpeg (видео→телефон, звук→Дек)
│   ├── ffmpeg         # ← положи сюда (см. выше)
│   └── web/           # страница для телефона (index.html + mpegts.js)
└── package.json
```

## Нюансы / что проверить на Деке

- **Звук от root.** Бэкенд Decky работает от root, поэтому `main.py` направляет ffmpeg
  в аудиосессию пользователя через `PULSE_SERVER=unix:/run/user/1000/pulse/native`.
  Если звука нет — проверь, что сокет существует: `ls /run/user/1000/pulse/`.
- **Задержка/синхрон.** Видео по сети идёт с лагом ~1–2 сек, звук на Деке специально
  задерживается под него (ползунок на странице телефона).
- **Нагрузка на CPU.** Сейчас кодирование `libx264`. Для минимальной нагрузки в играх
  переключим на аппаратное VAAPI (закомментировано в `bin/server.py`).
